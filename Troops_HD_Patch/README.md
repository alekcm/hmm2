# Troops HD Patch

Готовый overlay с более плотной геометрией и улучшенными копиями текстур существ Heroes V.
Исходные игровые ресурсы не меняются.

## Установка

Это **overlay, а не полная копия игровых данных**. В нём находятся только `Meshes/` и `Textures/` для моделей войск.

1. В Unity-проекте уже должна быть подготовлена базовая папка `Assets/StreamingAssets/HoMM5` с данными игры.
2. Скопируйте содержимое папки `Troops_HD_Patch/HoMM5` в существующую `Assets/StreamingAssets/HoMM5`.
3. Объедините папки и подтвердите замену совпадающих файлов. Не удаляйте базовую `HoMM5` и не заменяйте её целиком папкой patch: в patch нет `Game/`, карт и остальных ресурсов.

Файлы используют те же UID моделей и пути PNG, что исходный импорт, поэтому JSON и ссылки в игровых данных менять не требуется. Если базовой `HoMM5` ещё нет, сначала нужен полный импорт игровых данных.

## Что улучшено

- 175 моделей: один проход longest-edge bisect удваивает число треугольников, сохраняя исходную поверхность, UV-развёртки и художественный силуэт; нормали и skin weights интерполируются.
- 337 текстурных ресурсов: цветовые diffuse-карты, включая карты оружия, увеличены максимум в 1,5 раза (до 2048 px по длинной стороне) с умеренным повышением резкости. Effect/mirror/gloss-карты остаются исходного размера.
- Стиль, исходные цвета и формы не перерисовывались. Палитры PNG оптимизированы с дизерингом, чтобы patch оставался компактным. Полупрозрачные карты без полностью прозрачных пикселей сохраняются в RGBA PNG, чтобы не потерять их opacity.
- В исходных материалах существ не найдено слотов `Bump` и `DetailTexture`, поэтому такие карты не создавались. `Gloss` и `Mirror`-файлы включены, но patch не меняет Unity-шейдеры: текущий боевой рендерер использует базовую diffuse-текстуру, поэтому дополнительные карты потребуют отдельной интеграции в runtime.

`manifest.json` содержит список файлов, UID и размеры до/после обработки.

## Пересборка

Из корня репозитория, при установленном ImageMagick:

```bash
python3 tools/troop_hd/build_patch.py --out Troops_HD_Patch
```
