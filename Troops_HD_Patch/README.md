# Peasant — прототип локального HD-улучшения

Это намеренно **один проверочный объект** — крестьянин Haven Peasant. Предыдущая массовая генерация, которая лишь делила треугольники и увеличивала текстуры, из PR удалена: она не выполняла критерии качества.

## Готовый overlay

Содержимое `Troops_HD_Patch/HoMM5/` можно скопировать с объединением и заменой совпадающих файлов в существующую `Assets/StreamingAssets/HoMM5/` Unity-проекта. В overlay только два игровых ресурса:

- `Meshes/B609BA27-66B2-4F26-B681-EF5F7F3A4601.glb` — модель Peasant;
- `Textures/Textures/Textures/auto-imported_______320/dev/Test/TMPcharacters/Peasant/Peasant.tga.dds.png` — его diffuse-атлас.

Это **не полная папка игровых данных**: не удаляйте базовую `HoMM5/` и не заменяйте её целиком. Нужны исходные игровые ресурсы и их `Textures/_manifest.json`; папка overlay предназначена именно для добавления поверх них.

## Что изменено

- Локально округлены рука/кисть, верх головы с капюшоном и кошель у пояса по skin weights Peasant. Поверхность остальных частей тела не сглаживалась глобально.
- `BodyShape`: 1 342 → 2 201 вершина, 1 670 → 3 142 треугольника; смещены 353 исходные вершины. Новые полигоны добавлены там, где они поддерживают изменение формы, а не как отдельное увеличение счётчика.
- `PitchForkShape` — отдельный mesh-блок: все 200 вершин и 182 треугольника сохранены без изменений; острые зубцы вил не сглаживались.
- В diffuse-атлас добавлены низкоконтрастное переплетение синей ткани и локальная зернистость кожи кошеля/капюшона. Исходная палитра и нарисованный стиль сохранены. Атлас стал 1024×1024 вместо 512×512, но увеличение разрешения само по себе не считается улучшением — видимая микродеталь добавлена в diffuse RGB.

`manifest.json` содержит размеры и статистику сборки. В `previews/` находятся software-render сравнения «до/после» и крупный план атласа; это диагностические превью bind pose, не скриншоты Unity. В статической позе вилка может выглядеть отделённой от кисти: её отдельный skin-weighted mesh сохранён без изменений, а анимация здесь не проигрывается.

## Пересборка

Из корня репозитория, при наличии ImageMagick (`convert`):

```bash
python3 tools/troop_hd/build_peasant_poc.py --out Troops_HD_Patch
```

Структурная проверка GLB выполняется сборщиком. Unity import/build здесь не запускался: в импортёре и Unity-проекте остаются существующие merge-маркеры. После визуальной проверки прототипа можно решить, распространять ли этот подход на другие модели.
