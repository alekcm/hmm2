# Peasant — прототип локального HD-улучшения

Это намеренно один проверочный объект — крестьянин Haven Peasant. В PR больше нет массовой генерации сеток для остальных существ; добавлена только доработка геометрии Peasant.

## Готовый overlay

Содержимое `Troops_HD_Patch/HoMM5/` копируйте с объединением и заменой файлов в существующую `Assets/StreamingAssets/HoMM5/` Unity-проекта. Оставьте базовые игровые данные и их `Textures/_manifest.json`: этот overlay не является полной копией игры.

- `Meshes/B609BA27-66B2-4F26-B681-EF5F7F3A4601.glb` — новая геометрия Peasant.
- `Textures/` — все 337 PNG-ресурсов материалов из предыдущего коммита `ec289b38d`, восстановленные без изменений. Я не добавлял к ним новую микродетализацию и не редактировал атласы в этой итерации — их можно заменить вручную, сохраняя пути.

## Что изменено в геометрии

- По skin weights локально округлены кисти, верх головы/капюшон, бёдра и голени, а также кошель у пояса. Для ног использованы кости `L_Thig/L_Leg` и `R_Thig/R_Leg`; веса стоп участвуют только в переходе у щиколотки, носки и подошвы не выбирались для сглаживания.
- Коэффициенты локального Loop-сглаживания удвоены относительно предыдущего прототипа. На полностью взвешенных вершинах действует защитный предел в один полный Loop-шаг, чтобы не допустить переразлёта формы; поэтому фактическое смещение отдельных вершин не обязано быть ровно вдвое больше.
- `BodyShape`: 1 342 → 3 049 вершин, 1 670 → 4 550 треугольников; смещены 687 исходных вершин. Треугольники добавляются локально в выбранных сегментах, где они поддерживают округлённую форму.
- `PitchForkShape` — отдельный mesh-блок: сохранены все 200 вершин и 182 треугольника; зубцы вил не сглаживались.

## Автоматический выбор участков

Для этого Peasant маски строятся по весам костей: это позволяет автоматически распространить сглаживание по конечностям и выбранным частям, не выделяя вручную каждый полигон. Перенос на другие модели можно частично автоматизировать по именам/иерархии костей, skin weights и геометрии поперечного сечения. Но распознавание того, что в конкретном стиле должно остаться острым (оружие, броня, подошвы, декоративные края), лучше подтверждать визуально — полностью безошибочного универсального правила тут нет.

## Превью и пересборка

`previews/geometry_comparison.png` показывает до/после для руки, головы/шапки, ног/голеней и кошеля. Это software-render диагностической bind pose, с одной и той же исходной текстурой по обе стороны, чтобы сравнивать именно геометрию; это не скриншот Unity. В статической позе вилка может выглядеть отделённой от кисти: её mesh сохранён, анимация здесь не проигрывается.

Из корня репозитория пересобрать GLB и manifest можно командой:

```bash
python3 tools/troop_hd/build_peasant_poc.py --out Troops_HD_Patch
```

Сборщик не меняет и не перезаписывает файлы в `HoMM5/Textures/`. Структурные проверки GLB и три теста прототипа проходят. Unity import/build не запускался: в импортёре и Unity-проекте остаются существующие merge-маркеры.
